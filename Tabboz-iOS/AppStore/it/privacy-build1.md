# Informativa sulla privacy di Tabboz

Tabboz è un gioco offline per iPhone e iPad, distribuito da ISTITUTI EDMONDO DE AMICIS SRL.

## Dati raccolti

Questa versione dell'app non raccoglie né invia allo sviluppatore dati personali, identificativi del dispositivo, dati di utilizzo o informazioni pubblicitarie. Non include pubblicità, strumenti di analytics, tracciamento o registrazione di account.

## Salvataggi

Il nome del personaggio, le preferenze e i progressi vengono memorizzati localmente sul dispositivo. L'app non li trasmette a un server dello sviluppatore. È possibile rimuoverli mediante il ripristino del personaggio o eliminando l'app e i relativi dati dal dispositivo.

## Backup scelti dall'utente

L'utente può esportare e importare un file JSON tramite l'app File di iOS. Il backup contiene i dati della partita, incluso il nome del personaggio scelto. Se l'utente salva il file in iCloud Drive o presso un altro fornitore, l'archiviazione e l'eventuale trasferimento dipendono dal servizio scelto e dalla sua informativa. Lo sviluppatore non riceve questi file automaticamente.

## Connessioni locali

Il gioco usa l'indirizzo di loopback 127.0.0.1 per caricare le risorse incluse nell'app. Questa connessione resta sul dispositivo e non rende il gioco accessibile dalla rete Wi-Fi o cellulare.

## Servizi Apple

Download, acquisti dell'app ed eventuali diagnostiche gestite dal sistema operativo sono regolati dalle impostazioni del dispositivo e dalle informative Apple. L'app non integra un proprio servizio di diagnostica o telemetria.

## Aggiornamenti e contatti

L'informativa verrà aggiornata se cambieranno le funzionalità o le pratiche relative ai dati. Per le richieste sulla privacy utilizzare il contatto di assistenza indicato nella pagina del prodotto sull'App Store.
